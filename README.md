# Sagar - Personal Developer Portfolio Website

> **Academic Degree:** Master of Computer Applications (MCA), 2026 – 2028  
> **Institution:** Poornaprajna Institute of Management (PIM), Udupi, Karnataka  
> **Technology Stack:** HTML5, CSS3, Vanilla JavaScript (Zero external dependencies)

---

## 🌟 Overview

A modern, fast, responsive, and accessible personal developer portfolio built for **Sagar**, a first-year MCA student at Poornaprajna Institute of Management (PIM), Udupi.

Designed strictly around authentic student data, uninflated skill ratings, and active academic explorations at PIM Udupi, this portfolio provides recruiters and academic coordinators with an honest, dignified, and polished presentation of Sagar's capabilities.

---

## 📁 Single Folder File Structure

All files reside together in **one single folder** (no subfolders required):

```
sagar_portfolio/
├── index.html       # Main portfolio landing page (fully styled)
├── style.css        # Modern CSS stylesheet with pastel dark & light theme
├── main.js          # Interactive JavaScript (theme toggle, filter, drawer, modal)
├── script.js        # Script alias for quick reference
├── avatar.svg       # Custom developer illustration
├── favicon.svg      # Custom <S/> browser favicon
├── resume.html      # Standalone printable/downloadable resume sheet
└── README.md        # Documentation and guide
```

---

## 🚀 How to Run & Preview

Double-click `index.html` in your file explorer, or right-click and choose **Open with > Chrome / Edge / Firefox**.

Everything connects directly from the same folder!
